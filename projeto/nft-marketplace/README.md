# KURIO — NFT Marketplace

Projeto React + TypeScript + Vite, atualizado.

## Iniciar

```bash
npm install
npx msw init public/ --save
npm run dev
```

Acesse o endereço mostrado pelo Vite. O arquivo `public/mockServiceWorker.js` é obrigatório e deve ser criado antes de executar; sem ele o MSW não inicia.
